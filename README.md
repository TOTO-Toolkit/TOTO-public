# TOTO public demo deployment

This repository is a public GitHub Pages deployment shell for the browser demo
only. The scientific source and the Windows installer remain private. Do not
add release assets, `.exe` files, application archives or private development
history here.

- Product: TOTO — Toolkit for Open Tracking and Observation
- Public demo: https://toto-toolkit.github.io/TOTO-public/
- Private installer requests: use the email button on the public demo.

The demo loads the checked-in MoveNet package in the browser, processes the
user's local video in temporary tab memory, and never uploads user video or
poses to GitHub. A CSV is downloaded only when the user explicitly chooses it.

The development source is maintained separately in the private repository
`TOTO-Toolkit/TOTO-demo`. Keep this repository limited to the static demo files
needed by GitHub Pages.
