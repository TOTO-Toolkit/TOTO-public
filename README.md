# TOTO private demo staging

This repository is a private staging copy for the browser demo. There is no
public GitHub Pages site, public release, public installer or public model
distribution at this time. Keep the repository private and do not add release
assets, `.exe` files, application archives or private research history.

- Product: TOTO — Toolkit for Open Tracking and Observation
- Publication status: closed until Fabian explicitly authorizes it
- Private installer requests: staged mailto behavior only; not a live public flow

The demo loads the checked-in MoveNet package in a private/local browser run,
processes a user's local video in temporary tab memory, and does not upload
user video or poses to GitHub. A CSV is downloaded only when the user explicitly
chooses it.

The development source is maintained separately in the private repository
`TOTO-Toolkit/TOTO-demo`. Keep this repository limited to private QA and
deployment preparation. Before any future publication, re-audit repository
visibility, Pages, releases, raw assets and all download links together.

Developed at TeHealP, Pontificia Universidad Católica del Perú.
Project lead: Fabian A. Nana. macOS port: Guillermo J. Armoa (not yet validated).
